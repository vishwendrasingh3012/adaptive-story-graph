# 📖 Adaptive Story Graph (Animated)

An interactive, adaptive storytelling application built with **Python**, **Tkinter**, and **NetworkX**.  
Each choice you make branches the story in a new direction — visualized in real time using an **animated, top-down hierarchical graph**.  
Your progress is automatically saved and can be revisited at any time.

---

## 🌟 Features

- 🧠 **Adaptive Storyline** – Every decision dynamically changes the story flow.  
- 🧩 **Graph Visualization** – Displays a clear, top-down hierarchy of your story path.  
- 💾 **Auto Save** – Progress and visited paths stored in a local JSON file.  
- 🔙 **Backtracking** – Go back to previous decisions anytime.  
- 🎨 **Modern GUI** – Simple and engaging interface made with Tkinter.  
- ⚙️ **Lightweight & Dependency-Free** – Works without Graphviz or PyGraphviz.

---

## 🏗️ Technologies Used

- **Python 3.8+**  
- **Tkinter** – for GUI interface  
- **NetworkX** – for graph structure and relationships  
- **Matplotlib** – for visualization  
- **JSON** – for data persistence
